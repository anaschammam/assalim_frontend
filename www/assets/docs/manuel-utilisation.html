Chapitre 1

Présentation de l'application

Découvrez ce qu'est Assalim et ses grandes fonctionnalités

Assalim est une solution de gestion commerciale complète, conçue pour les commerces de détail, parapharmacies et établissements de restauration. Elle intègre dans une seule interface web tous les outils nécessaires au pilotage de votre activité au quotidien : vente, achat, stocks, caisse, rapports et bien plus.

Chapitre 2

Connexion & Navigation

Comment accéder à l'application et s'y repérer

Captures pour la documentation : pour éviter la fenêtre de visite guidée (tableau de bord, POS), ouvrez l'application avec ?noTour=1 dans l'URL au moins une fois par session navigateur. Le script Playwright du dossier docs/scripts utilise un viewport 1920×1080, ajoute noTour=1, et pour les écrans POS recharge la première transaction de l’historique récent (il faut au moins une facture vente / achat selon l’écran, selon le type de document courant du POS).

2.1 Se connecter

Ouvrez votre navigateur web (Chrome, Firefox, Edge…) et saisissez l'adresse de votre instance Assalim (fournie par votre administrateur). La page de connexion s'affiche automatiquement.

1

Saisir vos identifiants

Entrez votre adresse e-mail et votre mot de passe dans les champs correspondants.

2

Cliquer sur "Se connecter"

Appuyez sur le bouton ou utilisez la touche Entrée de votre clavier.

3

Accès à l'application

Si vos identifiants sont corrects, vous êtes redirigé vers l'accueil (grille du Hub) ou vers la première page autorisée par votre profil. Le tableau de bord reste accessible depuis le Hub ou le menu latéral. Le menu de navigation latéral se présente par défaut replié après la connexion (ou l'inscription) : utilisez le bouton menu (menu / menu_open) dans la barre du haut pour l'afficher ou le masquer ; votre choix est mémorisé sur cet appareil.

Sur un poste déjà utilisé, la page peut afficher les profils mémorisés (initiales et prénom). Touchez un visage : si un PIN caisse est défini pour ce compte, un pavé numérique s’ouvre ; sinon saisissez le mot de passe. Autre compte ramène au formulaire e-mail / mot de passe.

⚠️ Sécurité
Ne partagez jamais votre mot de passe. En cas de connexion partagée sur un poste commun, pensez à vous déconnecter après chaque session via le menu utilisateur en haut à droite.

2.2 Mot de passe oublié

Si vous avez oublié votre mot de passe, cliquez sur le lien "Mot de passe oublié ?" en bas du formulaire de connexion.

1

Saisir votre adresse e-mail

Entrez l'e-mail associé à votre compte Assalim.

2

Recevoir le code OTP

Un code de vérification à usage unique (OTP) vous est envoyé par e-mail.

3

Saisir le code OTP

Entrez le code reçu sur la page de vérification.

4

Définir un nouveau mot de passe

Choisissez un nouveau mot de passe sécurisé et confirmez-le.

2.3 Interface générale

L'interface d'Assalim combine une barre de navigation latérale (menu, à gauche en français — à droite en arabe RTL), une barre d'outils supérieure et une zone de contenu principale.

Éléments de l'interface

  • Menu latéral : accès aux modules (regroupés par thèmes : ventes, achats, données de base, etc.). Il peut être masqué ou affiché via le bouton dédié dans la barre d'outils ; à l'issue d'une connexion ou d'un changement d'utilisateur, il est masqué par défaut pour laisser plus de place au contenu.
  • Barre d'outils (en-tête) : logo ou nom de l'établissement, puis à droite : icône applications (retour au Hub), centre de notifications / alertes (cloche), menu Aide (visite guidée, navigation rapide, manuel d'utilisation intégré), icône soleil ou lune (choix du thème clair, sombre ou automatique), langue (FR / EN / AR), changement d'utilisateur, menu compte (mot de passe, paramètres, mode kiosque, modes verrouillés, déconnexion). Sur un petit écran, plusieurs de ces actions sont regroupées sous le menu Plus (more_vert).
  • Bannières : selon votre déploiement, des bandeaux peuvent s'afficher (essai, licence à activer, licence expirée, mode hors ligne)
  • Bandeau de contexte documentaire : lorsque vous consultez un document vente ou achat, une barre colorée rappelle le flux (vente / achat), le type de document et des actions rapides
  • Zone de contenu : affiche la page ou le module sélectionné
  • Pied du menu latéral : rappel de l'utilisateur connecté et bouton de déconnexion
ℹ️ Interface trilingue
Assalim supporte le français, l'anglais et l'arabe. Le changement de langue se fait depuis l'icône langue dans la barre d'outils (ou le menu « Plus » sur petits écrans). L'interface passe en lecture de droite à gauche (RTL) lorsque l'arabe est sélectionné. Les tickets, PDF et exports suivent la langue et la devise configurées dans les paramètres de l'établissement.

2.4 Hub (centre d'applications)

Le Hub est la grille d'accueil : des tuiles colorées représentent les familles de fonctionnalités (ventes, achats, stock, rapports, etc.). Cliquez sur une tuile parent pour afficher les sous-modules, ou sur une tuile simple pour ouvrir directement une page (ex. tableau de bord, caisse).

L'icône applications (apps) dans la barre d'outils ramène toujours au Hub. Les tuiles affichées dépendent de vos droits et, pour le stock, du paramètre Désactiver la gestion de stock de l'établissement.

En haut du Hub, une bande d'actions rapides (caisse, POS, alertes…) dépend du type d'établissement. Un bandeau « Ouvrir l'app manager » mène à la vue téléphone /m (chapitre 16).

2.5 Thème d'affichage (clair ou sombre)

Vous pouvez adapter l'application à votre confort visuel ou à la luminosité du local. Cliquez sur l'icône soleil ou lune dans la barre d'outils (ou ouvrez le menu Plus sur téléphone ou tablette, puis la rubrique du thème).

  • Clair : fond clair, texte foncé.
  • Sombre : fond sombre, texte clair.
  • Système : Assalim suit le réglage jour / nuit de votre navigateur ou de votre appareil ; si vous changez le thème Windows ou macOS, l'application peut suivre automatiquement.

Votre choix est enregistré sur cet appareil : en vous reconnectant depuis le même navigateur, le thème revient comme vous l'aviez laissé.

2.6 Menu Aide : visite guidée, navigation rapide, manuel

Le bouton Aide (point d'interrogation) ouvre un menu avec trois entrées utiles au quotidien :

  • Découvrir l'interface : courte visite guidée des écrans principaux (tableau de bord, POS, etc.). Vous pouvez la quitter à tout moment.
  • Navigation rapide (Ctrl+K) : boîte de dialogue pour aller vite vers un module en tapant quelques lettres.
  • Manuel d'utilisation : ouvre ce guide dans l'application, pratique pour consulter une procédure sans quitter votre session. Le manuel suit la langue de l'interface (français ou arabe). Le bouton Exporter en PDF enregistre le guide dans cette même langue : dans la fenêtre d'impression, choisissez « Enregistrer au format PDF ».

2.7 Recherche universelle (Ctrl+K)

Appuyez sur Ctrl+K (ou ⌘K sur Mac) depuis n'importe quelle page pour ouvrir la palette de recherche. Saisissez quelques lettres pour trouver instantanément :

  • Un produit par nom ou code-barres
  • Un client ou fournisseur
  • Une facture par numéro
  • Un module de l'application

Naviguez avec les touches ↑ ↓, validez avec Entrée, fermez avec Échap.

💡 Astuce
La recherche universelle est le moyen le plus rapide de naviguer : moins de 2 secondes pour atteindre n'importe quel écran ou document.

2.8 Raccourcis clavier

Appuyez sur ? depuis n'importe quelle page (hors champ de saisie) pour afficher la liste des raccourcis disponibles. Vous pouvez aussi y accéder via Menu Aide → Raccourcis clavier (?).

RaccourciAction

2.9 Typographie paramétrable

Vous pouvez ajuster la taille du texte depuis le menu Thème (icône palette en haut à droite). Trois niveaux sont disponibles :

  • Compact : texte plus petit, plus d'informations à l'écran — idéal sur grandes tables et monitors.
  • Normal : taille standard recommandée.
  • Large : texte plus grand — idéal pour l'accessibilité ou les écrans distants.

Le choix est sauvegardé automatiquement et s'applique sur toute l'application.

ℹ️ Première connexion ou nouveau poste
Selon votre organisation, un assistant de configuration peut s'afficher au premier accès pour vous guider (société, utilisateurs, etc.). Des bannières en haut de l'écran peuvent aussi vous inviter à activer la licence ou à contacter votre administrateur : suivez les liens proposés sur la bannière.

2.10 Modes verrouillés (caissier / serveur)

En plus du mode kiosque (plein écran, sortie libre — voir §6.4), le menu compte (icône 👤) propose deux modes verrouillés destinés au personnel en salle ou en caisse. La sortie demande le mot de passe d'un gérant (sauf si un administrateur, gérant ou pharmacien est déjà connecté).

ModeÉcrans autorisésSortie
Mode caissier verrouilléPOS et caisse uniquement (pas de menu latéral)Échap ou bouton de sortie → mot de passe gérant
Mode serveur verrouilléPlan de salle, tables, comptoir (cloche notifications visible)Idem
Mode kiosquePlein écran libreSans PIN

Une déconnexion lève aussi le verrou. Ces modes évitent qu'un caissier ou un serveur n'ouvre les paramètres, les rapports ou d'autres modules pendant le service.

2.11 Mode tactile

Le mode tactile agrandit les boutons, les lignes de tableau et les champs (cibles d’environ 48 px) sur toute l’application — listes, factures, stock, menu — pas seulement la caisse. Il est activé par défaut sur chaque poste (caisse, tablette ou bureau).

  • Le clavier et les pavés numériques (login PIN, OTP, caisse, clôture, quantités) ont le même style partout : touches claires, cibles 48 px, actions en couleur primaire.
  • Menu compte (icône 👤) → Quitter le mode tactile pour un affichage compact à la souris, uniquement sur ce poste.
  • Même menu → Mode tactile pour le réactiver.
Chapitre 3

Tableau de Bord

Vue d'ensemble de vos indicateurs clés de performance

En bref
Le tableau de bord répond à : « Comment vont mes ventes aujourd'hui et ce mois-ci ? » — chiffre du jour, total du mois, marge, produits les plus vendus et graphiques. Ouvrez-le depuis le Hub ou le menu latéral lorsque vous avez besoin d'un coup d'œil rapide, sans passer par les rapports détaillés.

Après la connexion, vous arrivez en général sur le Hub (voir chapitre 2). Le tableau de bord s'ouvre depuis une tuile du Hub ou depuis le menu latéral. Il offre une vue synthétique et immédiate de l'état de votre activité commerciale.

Vue après défilement : bas du tableau de bord (même page qu’à la figure du chapitre 2 « Interface générale »), pour montrer graphiques et blocs situés sous la première hauteur d’écran. La capture est produite en viewport 1920×1080 après défilement automatique lors de la génération des images.

Les données du tableau de bord sont actualisées en temps réel. Vous pouvez forcer un rechargement en appuyant sur le bouton d'actualisation en haut de la page.

3.1 Dashboard personnalisable

Vous pouvez choisir quels widgets afficher sur le tableau de bord en cliquant sur l'icône Personnaliser (🔧) à côté du bouton Actualiser.

Un panneau s'ouvre avec la liste de tous les widgets disponibles :

  • KPIs — ventes/achats du jour, marge mensuelle
  • Session de caisse — état de la caisse ouverte
  • Ventes journalières — graphique en courbes sur 30 jours
  • Ventes par catégorie — graphique en secteurs (camembert)
  • Top produits — palmarès des produits les plus vendus
  • Ventes vs Achats — comparaison mensuelle
  • Alertes stock — produits en rupture ou faible stock
  • Propositions d'achat — compteur de réapprovisionnements à valider

Cochez/décochez librement. Cliquez Réinitialiser pour retrouver la configuration par défaut. Vos préférences sont sauvegardées automatiquement.

3.2 Plan d'action « Quoi faire demain »

Sous les indicateurs du jour, le tableau de bord affiche une liste classée « Quoi faire demain » lorsque des points d'attention existent. Chaque ligne ouvre l'écran utile (caisse, stock, périmés, créances, etc.).

Ordre de priorité typique :

  1. Caisse fermée
  2. Rupture de stock
  3. Péremption dans les 7 jours
  4. Créances de plus de 30 jours
  5. Stock faible
  6. Produits à marge négative
  7. Propositions d'achat à traiter
💡 Même liste sur téléphone
L'onglet Alertes de l'app manager (/m, chapitre 16) reprend exactement ce plan d'action.

Imprimer des étiquettes

Depuis la liste des produits : bouton Étiquettes A4 (page) (une étiquette 50×30 mm par unité de stock vendable de la page, stock 0 ignoré), bouton Codes-barres A4 (tous) (liste filtrée, deux codes par ligne, pastille 92×65 mm, photo si disponible) et, sur chaque ligne, l’icône étiquette pour un rouleau unitaire. Suppléments / options cuisine (HoReCa)

Sur la fiche produit (sans passer par Modifier), la carte Suppléments / options cuisine permet d’ajouter des extras (fromage, double viande, cuisson…) avec un éventuel supplément de prix. Ces options apparaissent ensuite à la caisse table ou comptoir. Réservé aux profils qui administrent le plan de salle (gérant, admin).

4.2 Catégories

Les catégories permettent d'organiser votre catalogue en familles logiques (ex. : Médicaments, Cosmétiques, Hygiène, Compléments alimentaires…).

Pour créer une catégorie, cliquez sur "+ Nouvelle catégorie", saisissez le nom et validez. Vous pouvez également modifier ou supprimer une catégorie existante via les icônes d'action à droite de chaque ligne.

⚠️ Suppression de catégorie
Une catégorie ne peut être supprimée que si aucun produit ne lui est rattaché. Réaffectez les produits avant de supprimer la catégorie.

4.3 Unités de mesure

Définissez toutes les unités utilisées dans votre activité : pièce, boîte, gramme, litre, etc. Ces unités sont sélectionnées lors de la création de chaque produit.

Chapitre 5

Clients & Fournisseurs

Gestion de votre carnet d'adresses commercial

5.1 Gestion des clients

La section Clients centralise toutes les informations sur vos acheteurs : coordonnées, historique des achats, solde et avances.

Créer un client

Cliquez sur "+ Nouveau client" et remplissez les informations suivantes :

  • Nom / Raison sociale (obligatoire)
  • Téléphone et adresse e-mail
  • Adresse postale
  • Condition de paiement par défaut
  • Plafond de crédit (0 = crédit non autorisé ; vide = pas de plafond)
  • Notes internes

Fiche client — détail

En cliquant sur un client dans la liste, vous accédez à sa fiche détaillée, qui affiche :

  • Ses coordonnées complètes
  • Son historique de commandes et factures
  • Ses paiements effectués et son solde en cours
  • Ses avances et acomptes

5.2 Gestion des fournisseurs

La section Fournisseurs fonctionne de manière identique à celle des clients, mais orientée vers vos partenaires d'approvisionnement.

Les informations spécifiques à un fournisseur incluent :

  • Nom commercial et raison sociale
  • ICE, numéro de registre de commerce (Maroc)
  • Contacts (téléphone, e-mail)
  • Historique des achats et factures fournisseur
  • Solde dû et historique de paiements

5.3 Conditions de paiement

Définissez les conditions de paiement standards de votre commerce (comptant, 30 jours, 60 jours net, etc.) et associez-les à vos clients et fournisseurs.

Chapitre 6

Point de Vente (POS)

Caisse rapide pour la vente et l'achat

En bref
Un seul écran tactile sert à la vente et à l’achat : catalogue à tuiles, ticket, pavé. Il n’y a plus de caisse « classique » à quatre colonnes. Le POS Vente encaisse ; le POS Achat enregistre une réception fournisseur. Remises et conversion : §6.3. Une session de caisse ouverte est en général nécessaire (chapitre 10).

6.1 POS Vente

Ouvrez Point de vente (/pos). La caisse s’ouvre sans le menu latéral ERP (tableau de bord masqué) : catégories (nom + second nom s’il est renseigné, comme les tuiles) et tuiles produit à gauche, ticket et pavé (reçu, quantité, remise) à droite. Dans Paramètres → Options de l'écran caisse (§15.9), vous pouvez masquer le catalogue (catégories et tuiles) : il reste le scan code-barres et la recherche, calés sur la largeur du ticket ; dès deux caractères, une liste temporaire permet de choisir le produit, puis le ticket occupe toute la largeur à gauche (colonnes alignées, boutons d’action visibles). Sans article, le ticket ne montre que le chip client (ou fournisseur en POS achat) et le pavé sert de calculatrice (+ − × ÷ =) ; dès qu’un produit est ajouté, le pavé redevient Reçu / Qté / Remise. Le bouton Calculatrice du bandeau (et du menu ⋮) ouvre une modale (pavé + − × ÷ =) sans masquer Encaisser ; fermez-la par la croix, le fond ou Échap. Le bouton Menu ERP réaffiche la barre et la sidenav. Sur téléphone ou tablette portrait, le ticket s’ouvre en feuille depuis la barre Ticket. L’historique (F8) est dans le bandeau du haut (pas dans l’en-tête du ticket). Un produit en rupture (stock vendable 0) peut être ajouté : une pastille « Rupture » s’affiche ; à l’encaissement, un dialogue demande de valider quand même. Le clavier tactile s’ouvre via l’icône clavier, pas au simple focus. Le bandeau propose aussi Actualiser, Calculatrice, Verrouiller la caisse (§6.11), restaurer le dernier ticket (F9) et vider le panier (F10) — pas de second bouton « vider » sur l’en-tête du ticket. Chaque ajout au ticket est enregistré tout de suite dans le navigateur : après un F5, le bouton Restaurer la dernière facture reste dans le bandeau (le ticket s’affiche vide tant que vous ne restaurez pas).

Effectuer une vente

1

Sélectionner ou scanner les produits

Touchez une tuile, ou scannez le code-barres (pistolet USB : pas besoin de toucher l’écran). Un code EAN collé dans la recherche est ajouté tout seul ; le champ se vide et le curseur y revient. Un seul X efface la recherche (pas le X du navigateur). Sur téléphone ou tablette, le bouton Scanner (icône appareil photo) ouvre la caméra — il est masqué sur une caisse 15–24″ (pistolet USB) et ne pilote pas le pistolet. Filtrez par catégorie ou favoris. Le filtre En stock est déjà actif à l’ouverture (§6.9) : les ruptures n’apparaissent pas dans les tuiles (le scan reste possible). Le bouton Utilisés 90 j (éteint par défaut) ne garde que les produits vendus au moins une fois sur les 90 derniers jours — tout le catalogue paginé, pas seulement les 12 produits rapides.

2

Ajuster les quantités

Sur le ticket, le nom occupe toute la largeur à côté de la vignette. En dessous : − / qté / +, le total, la croix puis ⋯, alignés d’une ligne à l’autre. Si le catalogue est masqué (§15.9), la barre de recherche s’aligne sur le ticket ; chaque ligne aligne les colonnes (prix, quantité, total) et affiche les boutons remise, retour, note et prix (le menu ⋯ reste en mode catalogue). Ou le pavé Qté. Toucher une ligne affiche son panneau remise et/ou retour (s’il y en a) et masque ceux des autres produits. Retoucher la ligne déjà sélectionnée la désélectionne. Remise, retour et options cuisine : ⋯ (mode catalogue) ou les boutons de la ligne (catalogue masqué) — menu du même style que Langue / Thème (§6.3).

3

Sélectionner un client (optionnel)

Le chip Client est toujours visible sur le ticket. Recherchez et associez un client : le solde, le plafond et la fidélité n’apparaissent qu’à ce moment-là (§6.10).

4

Encaisser

Choisissez le moyen (Espèces, Carte, Chèque, Crédit) sur le pavé, saisissez le reçu (ou Exact), puis Encaisser. Si les pourboires sont activés (§15.1), une ligne Pourboire apparaît en bas du bloc paiement (sous les moyens ou le mixte) : touchez-la et saisissez un montant MAD au pavé. Choisissez Espèces (tiroir) ou Inclus carte (le TPE prend facture + pourboire). Le montant et le mode sont conservés dans le brouillon (F5 / Restaurer) et enregistrés sur la facture. Le total facture ne change pas. Pour plusieurs moyens sur la même vente, utilisez Paiement mixte : toucher une ligne la sélectionne et le pavé Reçu en saisit le montant ; + Espèces / + Carte / + Chèque / + Crédit ajoute une part. Le crédit est le reliquat sur le compte client (pas un encaissement) : un client est obligatoire. Un droit de timbre peut s’ajouter selon les taux du §15.1 (hors CA, comme le pourboire). Encaisser + ticket imprime en même temps si l’option est visible.

5

Imprimer ou envoyer le reçu

Si une imprimante ticket réseau est renseignée sur le poste de caisse (hôte, port 9100), le ticket part en ESC/POS ; sinon l’aperçu navigateur. Un encaissement espèces peut ouvrir le tiroir si l’option est cochée. Un reçu peut aussi être envoyé par e-mail.

ℹ️ Session de caisse
Pour utiliser le POS, une session de caisse doit être ouverte au préalable (voir Chapitre 10 — Caisse). Si aucune session n'est active, l'application vous invite à en ouvrir une.

6.2 POS Achat

Le POS Achat (/purchase-pos ou menu POS Fournisseur) est le même écran tactile que la vente, avec un badge Achat et le chip fournisseur. Il enregistre une réception et met les stocks à jour.

1

Sélectionner le fournisseur

Le chip Fournisseur est toujours visible. Recherchez et sélectionnez le fournisseur : son solde s’affiche s’il est renseigné. Pas de fidélité ni de tarifs commerciaux à l’achat.

2

Scanner ou ajouter les produits reçus

Scannez chaque article ou sélectionnez-le dans la liste et saisissez la quantité reçue. Le bouton À commander (équivalent d’« En stock » en vente) est éteint par défaut : activez-le pour n’afficher que les ruptures et sous-seuils.

3

Vérifier les prix d'achat

Confirmez ou ajustez le prix d'achat de chaque article. L'historique de prix est conservé.

4

Valider la réception

Touchez Encaisser (ou l’équivalent Valider). Les stocks sont mis à jour immédiatement.

ℹ️ Conversion documentaire dans le POS Achat
Lorsque vous chargez un document (ex. commande fournisseur) en conversion dans le POS achat, la quantité source de chaque ligne s'affiche sous le sélecteur de quantité, comme en POS vente — détaillé en section 6.3 ci-dessous.

6.3 Remises, marge et conversion au POS

Les paragraphes ci-dessous complètent le POS Vente et le POS Achat lorsque vous transformez un document existant (devis, commande, bon de livraison / bon de réception, etc.) en un autre document depuis l'écran caisse, ou lorsque vous ajustez les prix au moment de l'encaissement.

Remise sur une ligne (POS Vente)

  • Toucher une ligne du ticket ouvre son panneau remise (si une remise est posée) et/ou retour, et masque les panneaux des autres produits. Retoucher la ligne déjà sélectionnée la désélectionne (panneaux fermés).
  • Si votre rôle peut modifier les produits (administrateur, pharmacien, gérant), ⋯ propose aussi Modifier le prix : un écran dédié enregistre le prix de vente catalogue du produit (pas seulement une remise sur le ticket). Si le produit a Bloquer modification de prix, l’entrée reste visible mais barrée et grisée.
  • Sur le ticket, touchez ⋯ sur la ligne puis Remise (ou le mode Remise du pavé) : pourcentage, montant ou prix forcé. Si le catalogue est masqué (§15.9), le bouton Remise est déjà sur la ligne. Si le produit a Bloquer remise, l’entrée Remise reste visible mais barrée et grisée ; la remise globale du ticket reste possible.
  • De même, ⋯ → Retour (ou le bouton Retour sur la ligne, catalogue masqué) saisit les quantités vendable / abîmé / périmé. Si le produit a Bloquer retour, l’entrée Retour reste visible mais barrée et grisée ; les retours achat restent possibles.
  • En mode pourcentage, le point du pavé saisit les décimales du taux (ex. 10,5 %). Le montant de ligne reste exact (14,50 − 10 % = 13,05). Seuls les totaux ticket (sous-total, dû, timbre, reçu, rendu) sont arrondis au pas des pièces (§15.1) : 13,05 → 13,10 si pas 0,10.
  • Le prix d'achat (PPH) de référence s’affiche s’il est renseigné : ne descendez pas trop bas.
  • Si le prix de vente effectif passe sous le PPH, une pastille sous PPH apparaît sur la ligne.

Conversion vers un autre document (quantité source)

Lorsque le POS est ouvert en mode conversion (par exemple devis → commande, commande → facture, bon de livraison → facture, ou équivalents côté achat), chaque ligne issue du document source affiche sous le sélecteur de quantité la mention « Qté source » : il s'agit de la quantité sur le document d'origine. Vous pouvez modifier la quantité sur le nouveau document tout en gardant cette référence visible.

  • POS Vente : conversion commande → facture ou bon de livraison ; affichage de la quantité source pour toutes les lignes importées.
  • POS Achat : même principe lors du chargement d'un document fournisseur en conversion dans le POS achat.

Commande restaurant / cuisine et facturation (POS Vente)

Si vous utilisez le module Horeca : une ligne de commande marquée annulée en cuisine peut être reprise lors de la conversion en facture depuis le POS. Une pastille indique ce statut ; la quantité à facturer est proposée à 0 (vous pouvez l'augmenter si une facturation partielle est nécessaire). La quantité source sur le document de commande reste affichée comme ci-dessus.

6.4 Mode kiosk (plein écran tablette)

Le mode kiosk masque la sidebar et la barre d'outils pour transformer le POS en application plein écran — idéal sur tablette en caisse ou en libre-service.

1

Activer

Menu compte (icône 👤) → Mode kiosque. L'écran passe en plein écran, la sidebar disparaît.

2

Quitter

Appuyez sur Échap ou survolez le coin supérieur droit pour faire apparaître le bouton Quitter le kiosque.

ℹ️ Kiosque ou mode verrouillé ?
Le kiosque est un plein écran sans mot de passe. Pour limiter un caissier au POS (sortie gérant), utilisez le mode caissier verrouillé du menu compte (§2.10).

6.5 Mode hors-ligne

Assalim détecte automatiquement la perte de connexion Internet. Lorsque vous êtes hors-ligne :

  • Une bannière rouge s'affiche en haut de l'écran.
  • Les ventes POS continuent de fonctionner normalement et sont sauvegardées localement.
  • Le nombre de ventes en attente de synchronisation est affiché sur la bannière.
  • Au retour de la connexion, une bannière orange indique la synchronisation en cours, puis disparaît automatiquement.
⚠️ Attention
Les achats, retours et modifications d'inventaire nécessitent une connexion active. Seules les ventes POS fonctionnent en mode hors-ligne.

6.6 Programme de fidélité au POS

Si le programme de fidélité est activé (Commercial → Fidélité, §14.1), un widget apparaît automatiquement dans le ticket dès qu'un client est sélectionné sur une facture. Ce n’est pas un interrupteur dans les options de l’écran caisse : sans client, rien n’est affiché.

  • Affiche les points cumulés et le niveau (Bronze / Argent / Or).
  • Affiche la progression vers le niveau suivant.
  • Permet de saisir un nombre de points à utiliser → une remise correspondante est appliquée automatiquement.

Les points sont crédités automatiquement après chaque vente validée.

6.7 Scan code-barres et GS1 DataMatrix

Trois façons d’ajouter un article par code :

  • Pistolet USB : tape dans la caisse comme un clavier. Un EAN (≥ 6 chiffres) part au panier sans rester coincé dans la recherche ni dans le pavé Reçu.
  • Barre de recherche : coller ou scanner un EAN ajoute le produit ; un nom (ex. ZIAJA) filtre le catalogue.
  • Bouton Scanner : visible seulement sur téléphone / tablette ; ouvre la caméra, puis le même lookup produit. Absent sur une caisse bureau (pistolet USB).

Le champ accepte un code EAN classique et un DataMatrix GS1 (souvent imprimé sur les cartons et les produits à lots). Le scan extrait automatiquement :

  • le GTIN (identifiant produit) pour retrouver l'article ;
  • le numéro de lot s'il est présent dans le code ;
  • la date limite de consommation (DLC) s'il est présente.

Ces informations sont proposées à l'ajout au panier (sélection de lot / DLC). Un code-barres simple (EAN-13) continue de fonctionner comme avant.

6.8 Affiche client

Sur un second écran (tablette face au client, écran caisse), ouvrez Affiche client depuis la barre d'actions du POS. Une fenêtre /pos/customer-display affiche en temps réel le panier, les quantités, le total à payer, les retours et les points de fidélité.

L'affiche se met à jour toute seule tant que le POS reste ouvert sur le poste principal. Un message promotionnel et un QR code (fidélité, avis, menu) peuvent être configurés dans les paramètres.

6.9 Catalogue : filtres En stock et Utilisés

Au-dessus des tuiles catalogue, à côté de la recherche, le bouton En stock n’apparaît que si la gestion de stock est activée (paramètre « Désactiver la gestion de stock » non coché, §15.1). À l’ouverture de la caisse vente, le filtre est déjà actif.

  • Activé (défaut vente) : seules les tuiles avec un stock vendable > 0 restent (toutes les catégories, recherche et favoris).
  • Désactivé : le catalogue complet revient, y compris les ruptures. Vous pouvez alors ajouter un article à 0. L’encaissement n’est possible que si Autoriser le stock négatif est activé (§15.1) : un dialogue demande confirmation, puis le stock vendable passe sous zéro. Sinon Encaisser reste bloqué.
  • Un scan code-barres d’un produit à stock 0 reste possible : le filtre ne concerne que les tuiles (et la liste de recherche si le catalogue est masqué, §15.9).
  • En POS Achat, le même emplacement affiche À commander (rupture et sous-seuil), éteint par défaut.

À côté, en POS vente seulement, le bouton Utilisés 90 j (éteint par défaut) limite les tuiles aux produits apparus sur une facture non annulée des 90 derniers jours. Combinable avec En stock, une catégorie ou la recherche. Contrairement à l’onglet Produits rapides (favoris + 12 derniers vendus), ce filtre pagine tout le catalogue concerné. Le scan d’un produit jamais vendu sur la période reste possible.

6.10 Client, solde et tarifs

Sur la caisse tactile, le chip Client (vente) ou Fournisseur (achat) est toujours sur le ticket. Le solde, la fidélité et les tarifs commerciaux ne se règlent pas dans Paramètres → Options de l'écran caisse (§15.9) : ils suivent le contexte.

  • Aucun tiers : pas de solde, pas de fidélité.
  • Client (vente) : solde et plafond s’il y en a (plafond 0 = crédit non autorisé) ; fidélité si le programme est actif (§6.6).
  • Fournisseur (achat) : solde seulement. Pas de fidélité.
  • Tarifs commerciaux (prix barré, badges grille / promo) : uniquement en vente, lorsqu’un tarif s’applique vraiment à la ligne.

6.11 Verrouiller la caisse

Ce n’est pas le mode caissier verrouillé du menu compte (§2.10). Ici, la session reste ouverte : un PIN caisse (défini sur l’utilisateur) permet de masquer le ticket pendant une pause.

  • Bandeau POS : bouton Verrouiller la caisse (à côté d’Actualiser). Sur écran étroit, l’action est dans le menu ⋮ du bandeau — plus de cadenas dans l’en-tête du ticket.
  • Un mur de visages s’affiche (fond flou) : touchez votre profil, saisissez le PIN. Le fond n’est pas refermable d’un tap.
  • Sans geste pendant le délai d’inactivité (paramètre « Verrouillage caisse après inactivité », défaut 90 s, 0 = jamais), le même overlay apparaît.
  • Recharger la page conserve le verrou jusqu’au PIN. Une déconnexion lève le verrou (pas de mur à la reconnexion, sauf réglage contraire).

Sans PIN caisse, le bouton ne verrouille pas. Distinct du kiosque (plein écran sans mot de passe, §6.4).

Chapitre 7

Transactions de Vente

Cycle complet de la vente : du devis à la facture

Assalim gère un cycle documentaire complet pour vos ventes. Chaque document peut être converti au suivant d'un simple clic, évitant toute ressaisie.

ℹ️ Cycle documentaire de vente
Devis → Commande → Bon de livraison → Facture → Paiement
Vous pouvez commencer à n'importe quelle étape selon votre processus interne.
ℹ️ Conversion depuis le POS
Si la conversion vers le document suivant s'effectue depuis l'écran POS Vente ou POS Achat, chaque ligne importée peut afficher la quantité source du document d'origine (voir chapitre 6, section 6.3).

7.1 Devis de vente

Un devis est une proposition commerciale envoyée au client avant toute commande ferme. Il n'a aucun impact sur les stocks.

Créer un devis

1

Nouveau devis

Cliquez sur "+ Nouveau devis" dans la liste des devis.

2

Sélectionner le client

Choisissez le client dans la liste ou créez-en un nouveau.

3

Ajouter les lignes

Ajoutez chaque produit avec sa quantité et son prix. Appliquez des remises si nécessaire.

4

Enregistrer et envoyer

Enregistrez le devis, puis imprimez-le ou envoyez-le par e-mail au client.

7.2 Commandes de vente

Une commande de vente confirme la demande du client. Elle peut être créée directement ou convertie depuis un devis accepté.

✅ Conversion depuis un devis
Ouvrez un devis accepté et cliquez sur "Convertir en commande". Toutes les lignes sont reprises automatiquement — aucune ressaisie nécessaire.

7.3 Bons de livraison

Le bon de livraison (BL) documente la sortie physique des marchandises du stock. Sa validation déclenche la diminution du stock correspondant.

⚠️ Impact sur le stock
La validation d'un bon de livraison réduit définitivement le stock des produits concernés. Vérifiez les quantités avant validation.

7.4 Factures de vente

La facture de vente est le document comptable officiel remis au client. Elle peut être générée depuis une commande ou un bon de livraison.

Actions sur une facture

  • Imprimer : générer un PDF imprimable
  • Envoyer par e-mail : transmettre la facture au client
  • Enregistrer un paiement : saisir un règlement partiel ou total
  • Joindre un fichier : attacher un document (bon de commande client, etc.)
  • Annuler : annuler la facture (avec justification)

7.5 Paiements clients

Gérez les règlements reçus de vos clients : paiements sur facture, avances et acomptes.

Mode de paiementDescription
EspècesRèglement en numéraire, impacte la caisse
Carte bancairePaiement par TPE
ChèqueChèque remis à l'encaissement
Virement bancaireVirement reçu sur le compte
AvanceAcompte déduit des prochaines factures

Un droit de timbre peut s’ajouter sur la part encaissée de chaque mode, selon les taux saisis en §15.1 (ex. 0,25 % sur les espèces au Maroc). Le montant du timbre est arrondi au pas des pièces (0,25 → 0,30 si pas 0,10). Il n’entre pas dans le CA de la facture (comme le pourboire). Il s’affiche sur le paiement, l’avance, le ticket et le rapport de clôture pour la part espèces.

7.6 Discussions et pièces jointes sur un document

Sur la fiche d'un devis, d'une commande, d'un bon de livraison ou d'une facture (et sur d'autres écrans similaires, selon vos droits), vous pouvez trouver deux blocs utiles pour le travail d'équipe :

  • Discussion liée au document : fil de messages réservé à cette pièce (différent de la messagerie générale du chapitre 13). Servez-vous-en pour demander une validation interne, prévenir la logistique ou laisser une note visible par les collègues qui ouvrent le même dossier. Au doigt : mêmes cibles et clavier tactile que dans Messages.
  • Pièces jointes : ajoutez des fichiers (PDF signé, bon de commande client scanné, photo, etc.) pour tout garder au même endroit que le document comptable.

Si vous ne voyez pas ces zones, votre profil n'a peut-être pas la permission correspondante : demandez à un administrateur.

7.7 Retours vente — Avoir client

Lorsqu'un client retourne des marchandises, vous créez un avoir client directement depuis la facture d'origine.

1

Ouvrir la facture

Allez dans Ventes → Factures, ouvrez la facture concernée.

2

Créer le retour

Cliquez sur Retour (icône). Une copie de la facture s'ouvre en mode retour.

3

Indiquer les quantités retournées

Pour chaque ligne, saisissez les quantités retournées et leur état (vendable / abîmé / périmé). Un produit avec Bloquer retour n’est pas ajouté au ticket avoir.

4

Valider

L'avoir est créé avec le numéro AVOIR-CLI-XXXX. Le stock est réintégré et un PDF est disponible.

📋 Rapport Avoirs clients
Retrouvez tous vos avoirs dans Rapports → Avoirs clients avec filtres par période et export CSV.

7.8 Partage WhatsApp

Sur la fiche d'une facture (et d'autres documents vente), un bouton WhatsApp ouvre une conversation préremplie (nom, n° de document, montant) vers le téléphone du client. Même principe pour une réservation (date, couverts, table) et une proposition d'achat (lignes + total vers le fournisseur).

⚠️ Numéro requis
Sans téléphone sur la fiche client / fournisseur, le bouton indique qu'aucun numéro n'est disponible. Le partage ouvre WhatsApp Web ou l'application installée ; il n'envoie pas le message à votre place.
Chapitre 8

Transactions d'Achat

De la proposition automatique au paiement fournisseur, en passant par les devis et commandes

Le module achat couvre l'approvisionnement : propositions automatiques, éventuels devis fournisseur, commandes, réceptions, factures et paiements.

ℹ️ Cycle documentaire d'achat
Proposition (suggestion automatique) → éventuellement Devis fournisseur → Commande → Bon de réception → Facture fournisseur → Paiement

8.1 Propositions d'achat

Les propositions d'achat sont générées automatiquement par le système en analysant les niveaux de stock et les seuils minimaux définis. Elles constituent une aide à la décision pour votre responsable achats.

8.2 Devis fournisseur

Le devis fournisseur est une demande de prix ou une proposition d'achat adressée au fournisseur avant de vous engager sur une commande ferme. Il se rapproche du devis de vente côté client, mais ici c'est vous qui sollicitez le fournisseur.

Ouvrez la liste Devis fournisseur dans le menu Achats, créez un nouveau devis, choisissez le fournisseur et les lignes (produits, quantités, prix négociés). Vous pouvez ensuite l'envoyer ou le convertir en commande d'achat lorsque le fournisseur accepte.

8.3 Commandes d'achat

Créez une commande d'achat (bon de commande) à adresser à un fournisseur. Elle peut être générée depuis une proposition ou créée manuellement.

8.4 Bons de réception

À la réception des marchandises, créez un bon de réception. Cette étape met à jour les stocks et enregistre les quantités effectivement reçues (qui peuvent différer de ce qui a été commandé).

8.5 Factures fournisseur

Enregistrez les factures reçues de vos fournisseurs pour un suivi comptable précis de vos engagements et de votre dette fournisseur.

Historique des prix d'achat

Assalim conserve l'historique des prix d'achat pour chaque produit. Vous pouvez consulter l'évolution des tarifs fournisseurs et détecter les variations.

8.6 Paiements fournisseurs

Enregistrez les règlements effectués à vos fournisseurs et suivez votre dette fournisseur en temps réel.

Stock & Inventaire

Cliquez une ligne ou l'icône œil pour ouvrir la fiche : type, valeur, dates, priorité, catégories et produits ciblés, puis Modifier ou Supprimer.

14.3 Grilles tarifaires

Accès : Commercial → Grilles tarifaires. Une grille définit des prix par produit (et éventuellement un palier de quantité minimale). Vous l'affectez au client depuis sa fiche (liste déroulante), pas depuis le POS.

1

Créer la grille

Nommez-la, ajoutez des lignes (produit, qté min, prix).

2

L'assigner au client

Ouvrez la fiche client et choisissez la grille dans le champ prévu.

3

Vendre au POS

Dès que ce client est sélectionné, le prix de la grille s'applique (avant promo et fidélité).

L'icône œil ouvre le détail : nom, statut actif, et les lignes (produit, quantité min, prix unitaire).

Chapitre 16

App manager mobile

Piloter l'activité depuis un téléphone (PWA ou APK Android)

L'app manager est une vue soignée pour le gérant en déplacement : chiffre du jour, état de la caisse, alertes stock / DLC, raccourcis. Elle n'embarque pas le POS complet (ouvrez le POS depuis l'onglet Plus si besoin).

16.1 PWA à l'adresse /m

Après connexion, ouvrez /m ou touchez le bandeau « Ouvrir l'app manager » sur le Hub. Trois onglets en bas : Accueil (CA, caisse, KPIs), Alertes (même plan d'action que le dashboard), Plus (POS, hub, stock, rapports, paramètres, déconnexion).

  • Pull-to-refresh : tirez vers le bas pour actualiser. Un rafraîchissement auto a lieu toutes les 45 s si l'onglet est visible.
  • Hors ligne : bandeau + données éventuellement en cache (fraîcheur ~10 min).
  • Installer : iPhone → Partager → Sur l'écran d'accueil. Android Chrome → d'abord déverrouiller la disposition de l'écran d'accueil, puis menu → Ajouter à l'écran d'accueil. En HTTP sur IP locale (ex. 192.168.x.x), Chrome crée un raccourci, pas une app « stores ».
ℹ️ Droits
L'app manager exige le droit dashboard:read (et les mêmes gardes que le reste : connexion, licence, configuration, mode verrouillé).

16.2 Application Android (APK)

Une APK Capacitor (com.assalim.app) ouvre la même vue /m en plein écran, avec l'icône Assalim. En mode pilote / LAN, l'app charge l'adresse du serveur (Mac ou PC qui fait tourner Assalim) : téléphone et serveur doivent être sur le même Wi‑Fi. Le Play Store n'est pas encore le canal de distribution.

⚠️ Installation
Autorisez les « sources inconnues » pour installer l'APK de débogage. Si l'IP du serveur change, il faut resynchroniser la configuration LAN de l'app.

Assalim Essentiel (Hanout)

Épicerie de proximité : interface simple, crédit client, stock mono-site

Assalim Essentiel correspond au trio GROCERY + profil d'expérience Simple + édition Essentiel. Le menu affiche quatre tuiles : Vendre, Carnet, Stock, Aujourd'hui. Devis, commandes, HoReCa et modules ERP avancés sont masqués (les données restent en base si vous repassez en Retail).

17.1 Profil Simple et hub

  • Setup guidé : commerce, caisse CAISSE1, import CSV facultatif, première vente.
  • POS vente : facture directe, espèces ou crédit client, scanner USB sans configuration.
  • Achat : réception directe fournisseur (payé / reste).
  • Caisse : ouverture, mouvements, clôture guidée (comptage avant affichage du théorique).
  • Hors ligne certifié : factures directes vente/achat en file ; inventaire, clôture et règlements ultérieurs bloqués avec message.

17.2 Carnet et relevé

Le menu Clients devient Carnet : soldes, tri, encaissement rapide sans nouvelle facture, historique auditable (lignes annulées conservées).

  • Encaisser : Carnet → client → montant → moyen → reçu.
  • Partager le relevé : menu avec WhatsApp (texte FR/AR prérempli via wa.me), export PDF (impression « Enregistrer au format PDF ») ou image PNG téléchargeable.
  • Aucun envoi automatique : vous appuyez sur Envoyer dans WhatsApp.

17.3 Montée vers Retail

Paramètres établissement : passer édition Retail et profil Standard. Une checklist s'affiche (sauvegarde, diagnostic, modules, 2e site, inventaire, formation). Le retour vers Essentiel masque sans supprimer.
