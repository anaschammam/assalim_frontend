Chapter 1

Overview of the application

Discover what Assalim is and its main features

Assalim is a complete business management solution, designed for retail shops, parapharmacies and food-service establishments. It brings together in a single web interface all the tools you need to run your day-to-day activity: sales, purchasing, stock, cash register, reports and more.

1.1 Main features

Module Description
HubApplication centre: quick-access tiles to modules (sales, purchasing, stock, etc.) according to your rights
DashboardSummary view of KPIs (turnover, margins, top products, today’s sales)
Point of Sale (POS)Single touch till (sales and purchasing): tiles, ticket, Charge keypad, split tender, barcode / GS1 scanner, customer display, PIN lock
SalesFull cycle: quote → order → delivery note → invoice → payment
PurchasingFull cycle: proposal → order → goods receipt → supplier invoice → payment
Stock & InventoryReal-time tracking, sites / warehouses, transfers, physical stocktakes, stock-out alerts
Cash registerOpening/closing the till, cash movements, closing report
ReportsSales, purchasing, margin and stock reports, CSV / Excel / PDF exports
HoReCaFloor plan, table orders, kitchen display (KDS), reservations, statistics, waiter call via QR, delivery board (phone / Glovo / Uber)
Mobile appManager view on a phone (/m): today’s turnover, cash register, alerts, shortcuts — PWA or Android APK
MessagingInternal messaging between users of your establishment
SettingsCompany configuration, users, roles, permissions, licence, database backup

1.2 Roles and user profiles

Assalim manages several access levels. An administrator can assign a role to each user according to their responsibilities.

Role Description Typical access
Administrator Full access to all features and settings Everything
Manager Supervision of sales, purchasing, reports and stock Sales, Purchasing, Stock, Reports
Pharmacist / Salesperson Sales operations, stock consultation POS, Sales, Stock (read)
Cashier Collections and cash-register operations POS, Cash register
Kitchen (KDS) Viewing and updating kitchen orders Kitchen display only
Platform admin Technical SaaS role: global configuration (e.g. system mail), no business access by default Instance settings, not the usual sales/purchasing flow
ℹ️ Custom permissions
An administrator can refine each user’s rights individually, granting or removing specific permissions independently of their general role.
Chapter 2

Sign-in & Navigation

How to access the application and find your way around

Screenshots for documentation: to avoid the guided-tour window (dashboard, POS), open the application with ?noTour=1 in the URL at least once per browser session. The Playwright script in the docs/scripts folder uses a 1920×1080 viewport, adds noTour=1, and for POS screens reloads the first transaction from recent history (you need at least one sales / purchase invoice depending on the screen, according to the POS current document type).

2.1 Sign in

Open your web browser (Chrome, Firefox, Edge…) and enter the address of your Assalim instance (provided by your administrator). The sign-in page is displayed automatically.

1

Enter your credentials

Enter your email address and password in the corresponding fields.

2

Click “Sign in”

Press the button or use the Enter key on your keyboard.

3

Access the application

If your credentials are correct, you are redirected to the home page (the Hub grid) or to the first page allowed by your profile. The dashboard remains available from the Hub or the side menu. The side navigation menu is collapsed by default after sign-in (or registration): use the menu button (menu / menu_open) in the top bar to show or hide it; your choice is remembered on this device.

On a station already used, the page may show remembered profiles (initials and first name). Tap a face: if a till PIN is set for that account, a numeric pad opens; otherwise enter the password. Other account returns to the email / password form.

⚠️ Security
Never share your password. If you use a shared workstation, remember to sign out after each session via the user menu at the top right.

2.2 Forgot password

If you have forgotten your password, click the “Forgot password?” link at the bottom of the sign-in form.

1

Enter your email address

Enter the email associated with your Assalim account.

2

Receive the OTP code

A one-time verification code (OTP) is sent to you by email.

3

Enter the OTP code

Enter the code you received on the verification page.

4

Set a new password

Choose a new secure password and confirm it.

2.3 General interface

The Assalim interface combines a side navigation bar (menu, on the left in French or English — on the right in Arabic RTL), a top toolbar and a main content area.

Interface elements

  • Side menu: access to modules (grouped by theme: sales, purchasing, master data, etc.). It can be hidden or shown via the dedicated button in the toolbar; after sign-in or a user switch, it is hidden by default to leave more room for content.
  • Toolbar (header): logo or establishment name, then on the right: applications icon (back to the Hub), notification / alert centre (bell), Help menu (guided tour, quick navigation, built-in user manual), sun or moon icon (light, dark or automatic theme), language (FR / EN / AR), user switch, account menu (password, settings, kiosk mode, locked modes, sign out). On a small screen, several of these actions are grouped under the More menu (more_vert).
  • Banners: depending on your deployment, banners may appear (trial, licence to activate, expired licence, offline mode)
  • Document context banner: when you view a sales or purchase document, a coloured bar recalls the flow (sales / purchasing), the document type and quick actions
  • Content area: displays the selected page or module
  • Side-menu footer: reminder of the signed-in user and the sign-out button
ℹ️ Trilingual interface
Assalim supports French, English and Arabic. Language is changed from the language icon in the toolbar (or the “More” menu on small screens). The interface switches to right-to-left (RTL) reading when Arabic is selected. Tickets, PDFs and exports follow the language and currency configured in the establishment settings.

2.4 Hub (application centre)

The Hub is the home grid: coloured tiles represent feature families (sales, purchasing, stock, reports, etc.). Click a parent tile to show sub-modules, or a simple tile to open a page directly (e.g. dashboard, cash register).

The applications icon (apps) in the toolbar always takes you back to the Hub. The tiles shown depend on your rights and, for stock, on the establishment setting Disable stock management.

At the top of the Hub, a strip of quick actions (cash register, POS, alerts…) depends on the establishment type. An “Open the manager app” banner leads to the phone view /m (chapter 16).

2.5 Display theme (light or dark)

You can adapt the application to your visual comfort or to the room lighting. Click the sun or moon icon in the toolbar (or open the More menu on a phone or tablet, then the theme section).

  • Light: light background, dark text.
  • Dark: dark background, light text.
  • System: Assalim follows the day / night setting of your browser or device; if you change the Windows or macOS theme, the application can follow automatically.

Your choice is saved on this device: when you sign in again from the same browser, the theme returns as you left it.

2.6 Help menu: guided tour, quick navigation, manual

The Help button (question mark) opens a menu with three entries useful every day:

  • Discover the interface: a short guided tour of the main screens (dashboard, POS, etc.). You can leave it at any time.
  • Quick navigation (Ctrl+K): a dialog to jump quickly to a module by typing a few letters.
  • User manual: opens this guide inside the application, convenient for consulting a procedure without leaving your session. The manual follows the interface language (French, English or Arabic). The Export PDF button saves the guide in that same language: in the print window, choose “Save as PDF”.

2.7 Universal search (Ctrl+K)

Press Ctrl+K (or ⌘K on Mac) from any page to open the search palette. Type a few letters to find instantly:

  • A product by name or barcode
  • A customer or supplier
  • An invoice by number
  • An application module

Navigate with the ↑ ↓ keys, confirm with Enter, close with Esc.

💡 Tip
Universal search is the fastest way to navigate: less than 2 seconds to reach any screen or document.

2.8 Keyboard shortcuts

Press ? from any page (outside an input field) to display the list of available shortcuts. You can also reach it via Help menu → Keyboard shortcuts (?).

ShortcutAction
Ctrl+KOpen universal search
?Keyboard shortcuts panel
EscLeave kiosk mode / close dialogs
F1Contextual POS help
Ctrl+EnterSubmit a form

2.9 Adjustable typography

You can adjust the text size from the Theme menu (palette icon at the top right). Three levels are available:

  • Compact: smaller text, more information on screen — ideal on large tables and monitors.
  • Normal: recommended standard size.
  • Large: larger text — ideal for accessibility or remote screens.

The choice is saved automatically and applies across the whole application.

ℹ️ First sign-in or new workstation
Depending on your organisation, a setup wizard may appear on first access to guide you (company, users, etc.). Banners at the top of the screen may also invite you to activate the licence or contact your administrator: follow the links offered on the banner.

2.10 Locked modes (cashier / waiter)

In addition to kiosk mode (full screen, free exit — see §6.4), the account menu (👤 icon) offers two locked modes intended for floor or till staff. Exit requires a manager password (unless an administrator, manager or pharmacist is already signed in).

ModeAllowed screensExit
Locked cashier modePOS and cash register only (no side menu)Esc or exit button → manager password
Locked waiter modeFloor plan, tables, counter (notification bell visible)Same
Kiosk modeUnrestricted full screenNo PIN

A sign-out also lifts the lock. These modes prevent a cashier or waiter from opening settings, reports or other modules during service.

2.11 Touch mode

Touch mode enlarges buttons, table rows and fields (targets of about 48 px) across the whole app — lists, invoices, stock, menu — not only the till. It is on by default on every station (till, tablet or desktop).

  • The on-screen keyboard and numeric pads (login PIN, OTP, till, close cash, quantities) use the same style everywhere: light keys, 48 px targets, primary actions.
  • Account menu (👤) → Exit touch mode for a compact mouse layout on this station only.
  • The same menu → Touch mode to turn it back on.
Chapter 3

Dashboard

Overview of your key performance indicators

In brief
The dashboard answers: “How are my sales today and this month?” — today’s figure, month total, margin, best-selling products and charts. Open it from the Hub or the side menu when you need a quick glance, without going through detailed reports.

After sign-in, you generally land on the Hub (see chapter 2). The dashboard opens from a Hub tile or from the side menu. It gives a synthetic, immediate view of your commercial activity.

Scrolled view: bottom of the dashboard (same page as the chapter 2 “General interface” figure), to show charts and blocks below the first screen height. The capture is produced at a 1920×1080 viewport after automatic scrolling when images are generated.

Indicators displayed

IndicatorDescription
Today’s turnoverTotal of sales collected today
Month salesCumulative sales for the current month
Gross marginDifference between turnover and purchase cost
Active customersNumber of customers with recent purchases
Top productsBest-selling products over the period
Sales by categoryTurnover breakdown by product family (chart)
Sales trendDaily or monthly trend chart
Recent advancesList of the latest deposits received
✅ Refresh
Dashboard data is updated in real time. You can force a reload by pressing the refresh button at the top of the page.

3.1 Customisable dashboard

You can choose which widgets to show on the dashboard by clicking the Customise icon (🔧) next to the Refresh button.

A panel opens with the list of all available widgets:

  • KPIs — today’s sales/purchases, monthly margin
  • Cash session — status of the open till
  • Daily sales — 30-day line chart
  • Sales by category — pie chart
  • Top products — ranking of best-selling products
  • Sales vs Purchases — monthly comparison
  • Stock alerts — products out of stock or low stock
  • Purchase proposals — count of replenishments to validate

Tick/untick freely. Click Reset to restore the default configuration. Your preferences are saved automatically.

3.2 Action plan “What to do tomorrow”

Below today’s indicators, the dashboard displays a ranked list “What to do tomorrow” when attention points exist. Each line opens the relevant screen (cash register, stock, expired items, receivables, etc.).

Typical priority order:

  1. Till closed
  2. Stock-out
  3. Expiry within 7 days
  4. Receivables over 30 days
  5. Low stock
  6. Negative-margin products
  7. Purchase proposals to process
💡 Same list on the phone
The Alerts tab of the manager app (/m, chapter 16) reuses this action plan exactly.

Chapter 6

Point of Sale (POS)

Fast till for sales and purchasing

In brief
One touch till is used for both sales and purchasing: product tiles, ticket, keypad. There is no longer a four-column “classic” checkout. The Sales POS collects; the Purchase POS records a supplier receipt. Discounts and conversion: §6.3. An open cash session is generally required (chapter 10).

6.1 Sales POS

Open Point of sale (/pos). The till opens without the ERP sidebar (dashboard hidden): categories (name + second name if set, like product tiles) and product tiles on the left, ticket and keypad (tender, quantity, discount) on the right. In Settings → Till screen options (§15.9) you can hide the catalogue (categories and tiles): barcode scan and search remain, aligned with the ticket width; from two characters a temporary list lets you pick the product, and the ticket uses the extra width (aligned columns, action buttons visible). With no line, the ticket shows only the customer chip (or supplier on the purchase POS) and the keypad is a calculator (+ − × ÷ =); as soon as a product is added, it becomes Tendered / Qty / Discount again. The Calculator button on the top bar (and in the ⋮ menu) opens a modal (+ − × ÷ =) without hiding Charge; close it with the X, the backdrop or Escape. Show ERP menu brings the chrome back. On a phone or portrait tablet, the ticket opens as a sheet from the Ticket bar. History (F8) is on the top action bar (not in the ticket header). An out-of-stock product (sellable stock 0) can still be added: an “Out of stock” badge appears; at Charge, a dialogue asks you to confirm anyway. The on-screen keyboard opens from the keyboard icon, not on focus. The bar also offers Refresh, Calculator, Lock the till (§6.11), restore last ticket (F9) and clear cart (F10) — no second clear button on the ticket header. Each item added to the ticket is stored in the browser at once: after F5, Restore last invoice stays on the bar (the ticket stays empty until you restore).

Make a sale

1

Select or scan products

Tap a tile, or scan the barcode (USB gun: no need to touch the screen). An EAN pasted in search is added on its own; the field clears and the cursor returns there. A single X clears search (not the browser’s extra X). On a phone or tablet, the Scan button (camera icon) opens the camera — it is hidden on a 15–24″ till (USB gun) and does not drive the gun. Filter by category or favourites. The In stock filter is already on when you open the till (§6.9): out-of-stock items are hidden from tiles (scanning still works). The Used 90 d button (off by default) keeps only products sold at least once in the last 90 days — the full paged catalogue, not just the 12 quick products.

2

Adjust quantities

On the ticket, the name uses the full width next to the thumbnail. Below: − / qty / +, the total, the close button then ⋯, aligned from one line to the next. If the catalogue is hidden (§15.9), search lines up with the ticket; each line keeps aligned columns (price, quantity, total) and shows discount, return, note and price buttons (the ⋯ menu stays in catalogue mode). Or the Qty keypad. Tap a line to show its discount and/or return panel (if any) and hide the other products’ panels. Tap the already selected line again to deselect it. Discount, return and kitchen options: ⋯ (catalogue mode) or the line buttons (catalogue hidden) — same style as Language / Theme (§6.3).

3

Select a customer (optional)

The Customer chip is always on the ticket. Search and associate a customer: balance, credit limit and loyalty only appear then (§6.10).

4

Charge

Choose the method (Cash, Card, Cheque, Credit) on the keypad, enter the amount received (or Exact), then Charge. If tips are enabled (§15.1), a Tip line appears at the bottom of the payment block (under the methods or split): tap it and enter a MAD amount on the pad. Choose Cash (drawer) or On card (the terminal takes invoice + tip). The amount and mode are kept in the draft (F5 / Restore) and stored on the invoice. The invoice total does not change. For several methods on the same sale, use Split payment: tap a line to select it and type the amount on the Received pad; + Cash / + Card / + Cheque / + Credit adds a share. Credit is the unpaid remainder on the customer account (not a tender): a customer is required. Stamp duty may be added according to the rates in §15.1 (outside turnover, like a tip). Charge + ticket prints at the same time if the option is visible.

5

Print or send the receipt

If a network receipt printer is set on the cash register station (host, port 9100), the ticket is sent as ESC/POS; otherwise the browser preview. A cash sale can pulse the drawer if the option is enabled. A receipt can also be emailed.

ℹ️ Cash session
To use the POS, a cash session must be opened first (see Chapter 10 — Cash register). If no session is active, the application invites you to open one.

6.2 Purchase POS

The Purchase POS (/purchase-pos or Supplier POS menu) is the same touch screen as sales, with a Purchase badge and the supplier chip. It records a receipt and updates stock.

1

Select the supplier

The Supplier chip is always visible. Search and select the supplier: their balance appears if it is set. No loyalty or commercial pricing on purchase.

2

Scan or add received products

Scan each item or select it from the list and enter the quantity received. The To order button (the purchase equivalent of “In stock”) is off by default: turn it on to show only stock-outs and items below minimum.

3

Check purchase prices

Confirm or adjust the purchase price of each item. Price history is kept.

4

Confirm the receipt

Tap Charge (or the equivalent Confirm). Stock is updated immediately.

ℹ️ Document conversion in the Purchase POS
When you load a document (e.g. a purchase order) in conversion in the purchase POS, the source quantity of each line is shown under the quantity selector, as in the sales POS — detailed in section 6.3 below.

6.3 Discounts, margin and conversion at the POS

The paragraphs below complete the Sales POS and Purchase POS when you transform an existing document (quote, order, delivery note / goods receipt, etc.) into another document from the till screen, or when you adjust prices at collection time.

Line discount (Sales POS)

  • Tap a ticket line to open its discount panel (if a discount is set) and/or return panel, and hide the other products’ panels. Tap the already selected line again to deselect it (panels close).
  • If your role can edit products (admin, pharmacist, manager), ⋯ also offers Edit price: a dedicated screen saves the product’s catalog sale price (not only a ticket-line discount). If the product has Block price change, the entry stays visible but struck through and greyed out.
  • On the ticket, tap ⋯ on the line then Discount (or the keypad Discount mode): percentage, amount or forced price. If the catalogue is hidden (§15.9), the Discount button is already on the line. If the product has Block discount, Discount stays visible but struck through and greyed out; ticket-wide discount remains available.
  • Likewise, ⋯ → Return (or the Return button on the line when the catalogue is hidden) enters saleable / damaged / expired quantities. If the product has Block return, Return stays visible but struck through and greyed out; purchase returns remain allowed.
  • In percentage mode, the keypad decimal point enters rate decimals (e.g. 10.5%). The amount in MAD is then rounded to the coin step (14.50 − 10% = 13.05 → 13.10 if the step is 0.10). The Sales / Line discounts recap, cash received and change use the same step (§15.1).
  • The reference purchase price (PPH) is shown if it is filled in: do not go too low.
  • If the effective selling price falls below PPH, a below PPH chip appears on the line.

Conversion to another document (source quantity)

When the POS is open in conversion mode (for example quote → order, order → invoice, delivery note → invoice, or equivalent on the purchase side), each line from the source document shows under the quantity selector the mention “Source qty”: this is the quantity on the original document. You can change the quantity on the new document while keeping this reference visible.

  • Sales POS: conversion order → invoice or delivery note; source quantity displayed for all imported lines.
  • Purchase POS: same principle when loading a supplier document in conversion in the purchase POS.

Restaurant / kitchen order and invoicing (Sales POS)

If you use the HoReCa module: an order line marked cancelled in the kitchen can be reused when converting to an invoice from the POS. A badge indicates this status; the quantity to invoice is proposed as 0 (you can increase it if a partial invoice is needed). The source quantity on the order document remains displayed as above.

6.4 Kiosk mode (tablet full screen)

Kiosk mode hides the sidebar and toolbar to turn the POS into a full-screen application — ideal on a tablet at the till or for self-service.

1

Enable

Account menu (👤 icon) → Kiosk mode. The screen goes full screen, the sidebar disappears.

2

Exit

Press Esc or hover the top-right corner to reveal the Exit kiosk button.

ℹ️ Kiosk or locked mode?
Kiosk is a full screen without a password. To restrict a cashier to the POS (manager exit), use locked cashier mode in the account menu (§2.10).

6.5 Offline mode

Assalim automatically detects loss of Internet connection. When you are offline:

  • A red banner is displayed at the top of the screen.
  • POS sales continue to work normally and are saved locally.
  • The number of sales waiting to be synchronised is shown on the banner.
  • When the connection returns, an orange banner indicates synchronisation in progress, then disappears automatically.
⚠️ Caution
Purchases, returns and inventory adjustments require an active connection. Only POS sales work in offline mode.

6.6 Loyalty programme at the POS

If the loyalty programme is enabled (Commercial → Loyalty, §14.1), a widget appears automatically on the ticket as soon as a customer is selected on an invoice. This is not a toggle in till screen options: with no customer, nothing is shown.

  • Shows accumulated points and the level (Bronze / Silver / Gold).
  • Shows progress towards the next level.
  • Lets you enter a number of points to redeem → a corresponding discount is applied automatically.

Points are credited automatically after each confirmed sale.

6.7 Barcode scan and GS1 DataMatrix

Three ways to add an item by code:

  • USB gun: types into the till like a keyboard. An EAN (≥ 6 digits) goes to the basket without getting stuck in search or the Tender keypad.
  • Search bar: pasting or scanning an EAN adds the product; a name (e.g. ZIAJA) filters the catalogue.
  • Scan button: shown only on phone / tablet; opens the camera, then the same product lookup. Hidden on a desktop till (USB gun).

The field accepts a classic EAN code and a GS1 DataMatrix (often printed on cartons and lot-tracked products). The scan automatically extracts:

  • the GTIN (product identifier) to find the item;
  • the lot number if it is present in the code;
  • the use-by date (DLC) if it is present.

This information is offered when adding to the basket (lot / use-by selection). A simple barcode (EAN-13) continues to work as before.

6.8 Customer display

On a second screen (tablet facing the customer, till screen), open Customer display from the POS action bar. A /pos/customer-display window shows in real time the basket, quantities, amount due, returns and loyalty points.

The display updates by itself as long as the POS stays open on the main station. A promotional message and a QR code (loyalty, reviews, menu) can be configured in settings.

6.9 Catalogue: In stock and Used filters

Above the catalogue tiles, next to search, the In stock button appears only if stock management is enabled (“Disable stock management” unchecked, §15.1). When you open the sales till, the filter is already on.

  • On (sales default): only tiles with sellable stock > 0 remain (all categories, search and favourites).
  • Off: the full catalogue returns, including out-of-stock items. You can then add a zero-stock item. Charge is only possible if Allow negative stock is on (§15.1): a dialog asks for confirmation, then sellable stock goes below zero. Otherwise Charge stays blocked.
  • A barcode scan of a zero-stock product still works: the filter only affects the tiles (and the search list if the catalogue is hidden, §15.9).
  • On the Purchase POS, the same slot shows To order (stock-outs and below minimum), off by default.

Next to it, on the sales POS only, the Used 90 d button (off by default) limits tiles to products that appeared on a non-cancelled invoice in the last 90 days. It combines with In stock, a category or search. Unlike the Quick products tab (favourites + last 12 sold), this filter pages the full matching catalogue. Scanning a product not sold in that window still works.

6.10 Customer, balance and pricing

On the touch till, the Customer (sale) or Supplier (purchase) chip is always on the ticket. Balance, loyalty and commercial pricing are not set in Settings → Till screen options (§15.9): they follow the context.

  • No party: no balance, no loyalty.
  • Customer (sale): balance and limit if any (limit 0 = credit not allowed); loyalty if the programme is on (§6.6).
  • Supplier (purchase): balance only. No loyalty.
  • Commercial pricing (strikethrough, list / promo badges): sale only, when a price actually applies to the line.

6.11 Lock the till

This is not locked cashier mode in the account menu (§2.10). The session stays open: a till PIN (set on the user) hides the ticket during a break.

  • POS action bar: Lock the till (next to Refresh). On a narrow screen, the action is in the bar’s ⋮ menu — no padlock on the ticket header.
  • A face wall appears (blurred background): tap your profile, enter the PIN. Tapping the backdrop does not dismiss it.
  • With no gesture for the idle delay (setting “Lock till after inactivity”, default 90 s, 0 = never), the same overlay appears.
  • Reloading the page keeps the lock until the PIN is entered. Signing out clears the lock (no wall on the next sign-in, unless configured otherwise).

Without a till PIN, the button does not lock. Distinct from kiosk mode (full screen with no password, §6.4).

Mobile manager app

Steer the activity from a phone (PWA or Android APK)

The manager app is a polished view for the manager on the move: today’s figure, till status, stock / use-by alerts, shortcuts. It does not include the full POS (open the POS from the More tab if needed).

16.1 PWA at the /m address

After sign-in, open /m or tap the “Open the manager app” banner on the Hub. Three tabs at the bottom: Home (turnover, till, KPIs), Alerts (same action plan as the dashboard), More (POS, hub, stock, reports, settings, sign out).

  • Pull-to-refresh: pull down to refresh. An auto-refresh occurs every 45 s if the tab is visible.
  • Offline: banner + data possibly cached (freshness ~10 min).
  • Install: iPhone → Share → Add to Home Screen. Android Chrome → first unlock the home-screen layout, then menu → Add to Home screen. Over HTTP on a local IP (e.g. 192.168.x.x), Chrome creates a shortcut, not a “stores” app.
ℹ️ Rights
The manager app requires the dashboard:read right (and the same guards as the rest: sign-in, licence, configuration, locked mode).

16.2 Android application (APK)

A Capacitor APK (com.assalim.app) opens the same /m view full screen, with the Assalim icon. In pilot / LAN mode, the app loads the server address (Mac or PC running Assalim): phone and server must be on the same Wi‑Fi. The Play Store is not yet the distribution channel.

⚠️ Installation
Allow “unknown sources” to install the debug APK. If the server IP changes, the app’s LAN configuration must be resynchronised.

Neighbourhood grocery: simple UI, customer credit, single-site stock
